# 面试问答初稿

## 为什么先做 Fake gateway？

先验证输入、用例、响应和前端状态，避免模型渠道、密钥和网络不稳定掩盖业务问题。Fake 结果固定、可测试，但不能代表模型质量。

## 为什么报告暂存 JSON？

匹配报告字段仍在演进，JSON 能先保存完整结构；分数等稳定查询字段单独列出。契约稳定后再按查询需求规范化。

## 如何处理模型编造证据？

Prompt 要求证据回指输入；结果检查清单要求证据不足显式标记；评测集包含“经历未提供模型细节”的样例。最终仍需要人工复核。

## CORS 为什么只允许开发端口？

当前是本地 Vite 代理开发流，配置化允许来源并限制 API 方法。生产部署应使用实际前端域名、认证和更严格的安全策略。

## 下一步如何接真实模型？

先用环境变量运行普通文本、结构化输出和 Tool Calling 探测，记录状态码、耗时和错误类别；通过后再实现 gateway，并保留 Fake 回归测试。
