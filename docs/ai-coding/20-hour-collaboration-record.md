## 阶段 0：方案对比

| 方案 | 真实模型接入 | 结构化输出 | Tool Calling 边界 | 风险 | 验证命令 |
|---|---|---|---|---|---|
| A：直接 HTTP gateway | 复用现有 `AiGateway` 边界 | Java DTO 校验 | 仅无副作用预览 | 解析和超时处理需自建 | `mvn test -q` + 脱敏探测 |
| B：框架适配器 | 引入额外 AI 框架 | 框架 schema/解析 | 依赖框架能力和版本 | 依赖扩大、能力未证实 | 编译、契约测试 |
| C：Fake 优先 | 保留 Fake，真实接入延期 | 固定 fixture | 不实现副作用 | 无真实模型交付证据 | `mvn test -q` |

当前默认选择：先采用 A 的最小 gateway；若 endpoint 或模型能力探测失败，保留 C 作为演示回退。B 不在本轮引入，除非已有依赖和实验证据支持。
