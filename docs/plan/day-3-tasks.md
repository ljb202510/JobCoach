# 第 3 天任务：工具调用与执行记录

预计 6-8 小时。

1. AI/Codex（3.5 小时）：探测文本、结构化、工具调用能力，学习 LangChain4j 和 Agent loop，并记录 AI coding 调试证据。
2. 作品（2 小时）：把一个受控工具接入 JobCoach，形成可演示亮点。
3. Java 后端（1 小时）：实现必要的错误处理和执行状态记录。

学习验收：能解释 Tool Calling、Agent loop、Workflow 的区别，并说明模型不可信时如何控制边界。

工程验收：工具参数经过校验，只能写入允许的任务；成功、失败和超时均有记录。

防偏问题：工具是否真正服务于 JobCoach 的准备计划主线，而不是为了展示一个工具而添加？
