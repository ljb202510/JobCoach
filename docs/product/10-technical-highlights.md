- 以 Java 21/Spring Boot 分层实现岗位匹配用例，AI gateway 通过接口隔离 Fake 与真实实现。
- Vue 3 + TypeScript 页面打通 API，覆盖输入校验、加载、错误、空状态和结构化报告。
- 统一 `ApiError` 错误契约，并用真实 HTTP 请求验证 400、非法 JSON 和 CORS 预检。
- 用稳定 Fake fixture 先验证业务链路，再把真实模型能力拆成独立实验，不把兼容性当成结论。
- 设计执行记录、报告 JSON、准备计划和任务表，为后续持久化和审计保留边界。
- 已准备空输出、非法 JSON、缺字段和不安全工具参数的评测夹具；自动化评测尚未接入，不能据此宣称已覆盖。
