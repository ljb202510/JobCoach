# 后续 Agent 工作简报

## 任务背景

项目是 AI 求职教练系统 JobCoach，同时是求职作品和 AI coding 学习载体。

## 用户目标权重

- 简历项目作品：4/10。
- AI coding 全流程、AI 概念、工具和 Codex：4/10。
- Java 后端：2/10。

## 当前核心流程

岗位描述 + 个人经历 -> 匹配分析 -> 技能差距/证据 -> 准备建议 -> 用户确认后保存准备任务。

## 必须遵守

- 主力语言 Java；前端 Vue 3。
- 先检查现状和权威文档，再修改。
- 修改前说明文件范围；小步变更；运行测试；查看 diff；记录证据。
- 区分用户确认、代码事实、官方事实、草案和建议。
- 不索取/记录密钥，不扩展未授权功能。

## 接手顺序

1. 阅读 `docs/plan/PROJECT_GOALS.md`。
2. 阅读 `docs/engineering/status-matrix.md`。
3. 阅读当前任务对应的产品和代码文档。
4. 先报告发现和计划，再修改。
5. 回报：修改文件、测试命令/结果、风险、未完成项、需要用户确认的问题。
