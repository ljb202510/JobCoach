# JobCoach 产品简述

## 产品

AI 求职教练系统（JobCoach），帮助求职者依据目标职位要求和自己的经历，识别匹配证据与技能差距，并形成下一步准备任务。

## 目标用户

第一阶段以软件工程/计算机相关专业学生和初级求职者为主，尤其是准备 Java 后端或 AI 应用岗位的人。

## 核心价值

把“我适不适合这个岗位、还差什么、下一步做什么”转化为有证据、有优先级、可执行的准备建议。

## 不承诺

匹配分不是录用概率；AI 建议不是招聘方结论；系统不自动投递岗位。

## 用户问题拆解

1. 用户不知道岗位要求中哪些是硬技能、哪些是加分项。
2. 用户有项目经历，但不会把经历映射成岗位证据。
3. 用户知道差距，却缺少按优先级排列的下一步行动。
4. 用户需要看到“不足以判断”的地方，而不是被一个看似精确的分数误导。

## 价值链与边界

```text
岗位要求结构化 -> 经历证据映射 -> 差距/风险说明 -> 准备任务 -> 用户确认
```

系统的价值是帮助用户整理判断和行动，不替用户作出录用、投递或职业承诺。每个输出都应能回到岗位文本、经历文本或明确的通用规则。

## 产品验收

- 新用户能在 3 分钟内理解输入要求并提交一次分析。
- 报告同时展示匹配证据、证据不足和下一步行动。
- 用户能识别 fake/真实模型状态，不把演示夹具当成客观评分。
- 模型失败时输入仍保留，用户可以重试，不会生成伪成功记录。
