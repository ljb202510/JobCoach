# JobCoach 项目核心目标与协作约定

本文件是当前项目的目标基准。项目中文名为 **AI 求职教练系统**，英文名为 **JobCoach**。后续 Agent 或模型参与时，应先阅读本文件；若阶段计划与此处冲突，以用户最新明确决定为准，并同步更新本文档。

## 目标权重

按用户明确给出的投入比例安排时间和验收重点：

| 目标 | 权重 | 具体含义 |
|---|---:|---|
| 简历项目作品 | 4/10 | 项目可运行、可演示、可写进简历，并能讲清业务、架构、取舍和结果 |
| AI 概念、工具使用与 Codex | 4/10 | 学习 AI coding 开发全流程：如何让 AI 参与探索、需求拆解、方案设计、编码、调试、测试、Review、文档和复盘；同时理解模型调用、Agent、Tool、RAG、Skills、MCP 及其验证方法 |
| Java 后端 | 2/10 | 只学习支撑项目交付所需的 Spring Boot、API、测试、持久化和调试，不扩张成完整 Java 课程 |

时间和任务冲突时，优先保证前两项；Java 后端只做 JobCoach 主流程所必需的深度。

JobCoach 是学习载体，不是目标本身。任何时候不能为了快速完成页面而牺牲上述三类学习目标。

## 学习者与求职目标

- 软件工程专业大四，Java 基础一般，主力语言必须是 Java。
- 求职方向：Java 后端、AI 后端/全栈、Agent 开发。
- 通过真实项目训练代码阅读、调试、测试、设计、验证和 AI coding 工程工作流。
- 五天以广度优先，理解 AI 应用、Agent、工具调用、RAG、测试、Codex、Skills、MCP 的边界和局限。
- AI coding 不等于让 AI 一次性生成全部代码；重点是上下文准备、任务分解、约束提示、证据检查、渐进修改、测试验证和人工决策。

## 产品目标

JobCoach 是一个面向求职者的 AI 求职准备系统，帮助用户分析目标岗位与个人经历之间的差距，并生成可执行的准备计划。

第一版核心主线：

```text
岗位描述 + 个人简历/经历
    -> 匹配分析
    -> 技能差距和证据说明
    -> 面试准备建议
    -> 生成并保存学习/准备任务
```

## 五天内的 P0 交付

- 用户可以输入岗位描述和个人简历/项目经历；第一版不强制文件上传。
- 后端调用模型并返回结构化匹配报告：总体匹配、岗位要求、匹配证据、技能差距、风险和建议。
- 至少一个受控工具调用，例如保存准备任务计划；工具有白名单和参数校验。
- 保存分析报告、任务计划和执行步骤。
- Vue 页面支持输入、提交、加载、结果、任务和错误状态。
- 使用 fake AI gateway 完成核心业务测试；真实模型调用单独做能力探测。
- README 能指导启动、测试和演示，并明确已实现内容和局限。

## P1/P2 与非目标

- P1：面试题生成、任务状态更新、岗位技能检索、最小 RAG、模型渠道切换和流式输出。
- P2：文件解析、模拟面试、多 Agent、向量数据库、Redis、登录权限、岗位抓取、异步工作流和生产部署。
- 第一版不做自动投递、招聘网站爬虫、复杂社交功能、自动修改简历文件或保证求职结果。

## 技术与安全约束

- Java 21、Spring Boot、LangChain4j、Spring `RestClient` 兜底、MyBatis-Plus、MySQL、Vue 3、TypeScript、Vite。
- 具体依赖版本先核对官方兼容性，再固定到构建文件。
- 模型服务只通过环境变量配置；不索取、记录或提交 API Key。
- OpenAI 格式兼容不代表结构化输出、工具调用、流式或 Embedding 均可用，必须逐项验证。
- Docker Desktop/MySQL 当前未安装，先保留安装文档和 Compose 配置，不擅自安装。

## 教学与协作约定

- 每个任务说明目标、原因、预计耗时、改动范围和验收方法。
- 遵循：检查现状 -> 解释证据 -> 计划 -> 小步修改 -> 测试 -> diff/Review。
- 明确区分官方事实、作者经验和针对 JobCoach 的建议。
- 至少完成一次 Codex 计划/修改/测试/Review，一次项目级 Skill 实操，一次 MCP 概念或工具实操。
- 每天按验收标准复盘，完成后等待用户确认再进入下一天。
- 每个开发阶段都要记录 AI coding 流程：输入上下文、任务拆分、生成结果、人工检查、失败证据、修复方式、测试结果和复盘结论。

## 完成判据

JobCoach 的核心流程可运行、结果和失败可验证、文档可复现，且所有未完成项和局限均被明确记录；同时学习者能用自己的话解释关键代码路径、框架选择、验证方式和主要取舍，才算五天交付完成。
