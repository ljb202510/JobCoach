# 五天学习与交付总计划

项目：AI 求职教练系统（JobCoach）。输入岗位描述和个人经历，输出结构化匹配分析、技能差距和准备任务，通过受控工具保存任务计划，并记录执行过程。

技术基线：Java 21、Spring Boot、LangChain4j、Spring RestClient、MyBatis-Plus、MySQL、Vue 3、TypeScript、Vite、Docker Compose。具体依赖版本在官方兼容性核验后确定。

## 每天固定结构

每一天都同时包含：概念学习、项目实现、代码阅读/调试、测试验证、Codex 操作、用自己的话解释和复盘。完成代码不等于完成当天任务。

## 时间分配原则

按 4:4:2 分配精力：约 40% 用于可写进简历的 JobCoach 作品，约 40% 用于 AI coding 全流程、AI 概念、工具和 Codex 实操，约 20% 用于支撑项目所需的 Java 后端。每天的任务块会显式标注所属目标。

AI coding 全流程包括：检查现状、准备上下文、拆解任务、提出方案、限定改动、实施小步变更、运行测试、阅读错误、查看 diff、Review、记录决策和复盘。

## 路线

| 天数 | 任务 | 验收 |
|---|---|---|
| 1 | AI/Codex 地图与作品边界（AI 4，作品 4，后端 2） | 能解释术语和 AI coding 流程；有可写入简历的 MVP 设计 |
| 2 | 最小 Java 后端主链路（作品 4，后端 2，AI 4） | 主链路可测；能解释上下文、拆解、修改、测试和 Review 过程 |
| 3 | 模型、结构化输出、Tool、Agent（AI 4，作品 4，后端 2） | AI 能力有实验记录；核心亮点可演示 |
| 4 | Vue、RAG、测试和联调（作品 4，AI 4，后端 2） | 完成端到端作品；能解释 RAG 和局限 |
| 5 | 作品集包装、Review、面试和方法论（作品 4，AI 4，后端 2） | 能演示、写简历、讲清完整 AI coding 流程和必要后端 |

## 优先级

- P0：岗位+经历分析主流程、持久化、受控工具、Vue 页面、测试、README。
- P1：渠道切换、流式输出、MySQL 规则检索、最小 RAG。
- P2：Redis、向量数据库、多 Agent、登录、异步任务和部署。
