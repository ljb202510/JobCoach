# 依赖决策记录

## 已决定

- Java 主线，前端使用 Vue 3。
- 第一版优先评估 LangChain4j；通过 `AiGateway` 隔离框架。
- MySQL 用于持久化目标；Docker Compose 作为本地依赖方案。
- 暂不加入 Redis、向量数据库和多 Agent。

## 决策标准

依赖必须服务于作品集 4、AI/Codex 4 或 Java 后端 2；有官方兼容证据；能在五天内验证；失败时有最小替代方案。

## 待决定

- Spring Boot 与 LangChain4j 的具体兼容组合。
- MyBatis-Plus 是否在 P0 引入，还是先用 JDBC/MyBatis 完成学习目标。
- 真实模型渠道和结构化/工具能力。

## 决策操作单

1. 写问题和不可妥协约束：Java 21、Spring Boot 基线、可替换 gateway、五天可验证。
2. 查官方兼容性、最小示例和 provider 支持；记录日期和链接，不引用搜索摘要作为证据。
3. 用最小分支或实验比较候选依赖的编译、启动、测试、异常和替换成本。
4. 记录采用、拒绝或暂缓的理由，以及失败时保留的替代路径。
5. 依赖变更后更新 `pom.xml`、版本记录、状态矩阵、README 和复现命令。

## 禁止的决策捷径

- “最新版”不等于与当前 Spring Boot 兼容。
- “兼容 OpenAI”不等于结构化、Tool、流式和 Embedding 都可用。
- “社区常用”不等于适合五天目标、可测试且有降级路径。
