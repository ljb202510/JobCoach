# JobCoach 演示脚本（Fake 模式）

1. 在 `backend` 执行 `mvn spring-boot:run`，在 `frontend` 执行 `npm run dev`。
2. 输入岗位描述和个人经历，点击“分析岗位匹配”；浏览器通过 Vite 代理调用 `POST /api/matches`。
3. 说明报告中的岗位要求、匹配证据、技能差距和建议；特别展示“证据不足”而非编造。
4. 清空任一输入，展示按钮禁用和空输入提示；停止后端后重试，展示网络错误状态。
5. 明确标注：本演示使用 `fake` gateway，分数和内容是稳定夹具，不代表真实模型效果。

准备任务、保存状态和执行记录属于数据库/工具调用后续演示，不在当前 Fake 闭环中冒充已完成。

演示中明确标注是否使用真实模型或 fake 模式，不把 fake 结果说成真实模型能力。

## 演示前检查

1. 清理输入中的姓名、联系方式、内部岗位地址、API key 和本地绝对路径。
2. 运行后端 `mvn test -q`、前端 `npm run build`，确认演示版本与测试版本一致。
3. 用一组固定样例演示成功，再准备空输入、停止后端和结构失败的故障动作。
4. 检查页面加载、错误、重试、长文本和结果证据是否可见；不要只录成功截图。
5. 演示结束后说明 fake 的确定性、真实模型尚未验证的能力和下一步计划。

## 演示讲解结构

- 先讲用户问题和输入输出，不先讲框架名。
- 再展示一条报告证据如何对应岗位要求和个人经历。
- 然后说明分层、Fake gateway、错误契约和测试如何控制模型不确定性。
- 最后明确未实现功能、局限和下一步实验，避免把草案包装成生产能力。
