# 多 Agent 协作约定

## 适合委派

独立的只读研究、概念文档、测试审查或彼此不冲突的模块。一个主 Agent 负责目标、接口和集成。

## 委派卡

```text
目标和权威文档：docs/plan/PROJECT_GOALS.md
任务范围：
允许修改文件：
禁止修改文件：
输入/输出契约：
验证命令：
回报格式：证据、修改、测试、风险、未完成项
```

## 协作规则

- 先切分文件所有权或只读任务，避免并发改同一文件。
- 共享稳定的 API 契约，不共享相互矛盾的产品假设。
- 主 Agent 集成前检查 diff、测试和依赖兼容性。
- 多个 Agent 的共识不是事实证据；关键结论回到源码或官方文档核验。
