# 非功能需求草案

- 安全：密钥仅从环境变量读取；默认不持久化 API Key；工具采用最小权限。
- 可测试：业务层可注入 fake AI gateway，不要求测试时访问外网或真实模型。
- 可诊断：记录执行 ID、阶段和错误类别；避免记录不必要的简历全文。
- 可复现：README 列明 JDK、Maven、Node、MySQL/Docker 要求及命令。
- 可维护：模型适配与业务用例隔离；响应 DTO 有校验。
- 性能：MVP 只给出合理超时和可见加载状态，不宣称生产级 SLA。
- 隐私：简历属于个人敏感资料；存储策略、保留期限和删除能力在数据库实现前需确认。

## 非功能验收步骤

1. **安全**：扫描配置和日志，确认 key 只来自环境变量；工具测试越权、重复和未知参数。
2. **可测试**：替换 fake gateway，断开网络后仍能运行核心业务测试；记录测试边界。
3. **可诊断**：为一次请求生成执行标识，错误包含类别和阶段，不包含上游敏感头。
4. **可复现**：按 README 在干净终端执行启动和测试，记录缺失依赖、端口和版本问题。
5. **可维护**：检查 Domain 不依赖 Web/SDK；adapter 错误转换稳定；API 类型和文档同步。
6. **性能**：只测 MVP 合理超时和页面反馈，不提前宣称吞吐/SLA；记录样本和环境。
7. **隐私**：在真实模型和数据库实验前确认保留、删除、备份、供应商地域和用户提示。

## 失败处理优先级

任何非功能问题先保护用户数据和权限，再保证状态可解释，最后才优化速度和体验；不通过降低校验来换取演示成功。
