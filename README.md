# AI 求职教练系统（JobCoach）

一个以 Java 为主线、帮助求职者分析岗位匹配度并制定准备计划的 AI 应用，同时用于学习 Java AI 和 Agent 开发。

当前阶段正在实现最小可测试后端链路；真实模型、工具调用、MySQL 和前端按五天计划逐步加入。

文档入口：先读 [`docs/README.md`](docs/README.md)。其中 [`docs/plan/PROJECT_GOALS.md`](docs/plan/PROJECT_GOALS.md) 是唯一目标基准。

安全要求：不要提交真实 API Key、`.env` 或数据库密码，只提交 `.env.example`。
