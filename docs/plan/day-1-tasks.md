# 第 1 天任务：环境与设计

预计 6-8 小时。

1. AI/Codex（2.5 小时）：环境、术语地图、AI coding 全流程演练：探索、上下文、拆解、计划、Review。
2. 作品（2.5 小时）：JobCoach 用户流程、MVP、简历展示亮点和演示脚本。
3. Java 后端（1 小时）：只确认版本、目录和 API 边界。

学习验收：能用自己的话区分 Prompt、Skill、Tool、MCP Server、Agent、Workflow、RAG，并说出一个局限。

AI coding 验收：能说明一次任务中 AI 负责什么、自己负责什么、哪些证据才能接受 AI 的修改。

工程验收：环境表、能力矩阵、架构图、API 草案和复盘记录齐全。

防偏问题：今天是否只在准备“做什么”，而不是提前堆实现技术？
