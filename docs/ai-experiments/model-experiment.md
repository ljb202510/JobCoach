## 本机状态与耗时记录脚本

在真实模式后端运行时执行可复用脚本。它使用固定脱敏输入，只打印请求序号、HTTP 状态、耗时和结果类别，不打印响应正文或任何环境变量值：

```powershell
./docs/ai-experiments/test-local-api.ps1 -Count 3
```

将输出中的 `status`、`elapsedMs` 和结果类别填入 M20-02/M20-04；不要复制响应正文、Key 或完整输入。此前一次浏览器成功约 5.2 秒、HTTP 200；一次自动请求 17.299 秒、HTTP 504。两次不足以区分服务波动和 17 秒读取超时偏短，需观察重复请求分布。

2026-10-06 执行 `test-local-api.ps1 -Count 3`，结果依次为 `200/15130 ms/success`、`504/17074 ms/timeout`、`200/16202 ms/success`。成功请求已接近 17 秒阈值；可能是 Qwen 响应时间波动与当前阈值共同造成偶发超时。样本只有三次，尚不能量化稳定性或据此确定新的超时值，暂不修改配置。

同日以进程环境变量临时覆盖 `AI_BASE_URL=http://127.0.0.1:9/v1`，后端 API 返回 502。浏览器首次提交及点击重试各发出一次请求，均收到 502；两次均显示错误、保留输入且不显示报告。验证后已停止临时实例并按原 `.env` 重启后端；恢复后的真实请求返回 HTTP 504、19063 ms。
