# 第 2 天任务：Java 后端核心链路

预计 6-8 小时。

1. 作品（3 小时）：完成岗位+经历到匹配报告的可测试主链路。
2. AI/Codex（2 小时）：用 fake gateway 理解 AI 边界，完整执行一次“上下文准备→任务拆解→计划→修改→测试→diff→Review”。
3. Java 后端（1.5 小时）：只实现 DTO、校验、分层和测试所需内容。

学习验收：能解释 Controller、DTO、应用服务、AiGateway 为什么分层，以及 fake gateway 为什么有价值。

工程验收：后端可启动，`POST /api/matches` 在不依赖真实模型时可测试通过。

防偏问题：是否优先完成了可测试的主链路，而不是先接复杂 AI 框架？
